## 4. 当前「效果」到底怎么样（人话）

1. **声音**：MiniMax 男声能从 CD002 喇叭放出来，抽样 8 段已实测播放。  
2. **对话**：像「会惦记的陪伴」，不是百科客服；canon 题（怎么叫你/一辈子/到家）表现最好。  
3. **记忆**：会记住昵称等（测试中出现「小树」），但「还记得我上次说累吗」类回访仍不稳。  
4. **摄像头**：真的拍得到卧室画面；陪伴层只用动静，不乱描述隐私细节。  
5. **控电脑**：通知已通；写备忘录 App 仍受权限限制（已准备桌面文件退回）。
